1.0.0:
	-Release
1.0.1:
	-Added filter to remove bias frames with expime > 0 (bad focus images)
	-Config file adjusted to allow fits files of any name
	-Conda env file now explicitly describes channels to be used
	-Implemented astroscrappy for ccr, instead of lacosmicx
	-Added pipeline and script for running the DRP in real time at Keck
	-Changed logging to print more information about what files are being read when
	-Change ccdproc source to conda-forge to get latest version
	-Integrate TWIFLAT and DOMEFLAT frames into group mode
	-Enable recurring events option, allowing unordered files to be processed (sometimes)
1.0.2:
	-Changed headers in mflat and mbias to only store file names, not whole paths
	-Enabled -i CLI option
	-Fixed bug where bad pixels would cause entire slices to be masked, instead of single pixels
	-Added changelog
1.1.0:
	-Adds support for the red arm of KCWI
1.2.0:
	-Now uses python 3.12, allowing reductions on Apple Silicon CPUs, in addition to Intel and AMD
	-Added check_cals.py, which allows users to check whether they have the calibration files needed
	 before starting a full reduction
	-Allows for using input files with arbitrary names (no longer need to use only files as they
	 were named when they were first written to disk)
	-Fixes a bug that prevented two concurrent instances of the pipeline from running at the same time
	-Adds additional standard star spectra for use in fluxing
1.3.3:
	-Fixed StackFlats reading only the first flat N times (since 1.2.0): stacked flats now combine every input flat, and the stacked uncertainty is rescaled with the data
1.3.4:
	-Fixed MakeMasterFlat BM ledge correction: with several ledge peaks the highest one is now used (previously a position near the start of the search window), and when no ledge peak is found the correction is skipped with a warning instead of failing (previously no master flat was made, so no object frame could be reduced)
Unreleased:
	-Removed the Travis CI configuration (.travis.yml) and the Travis references in README.rst
	-There is currently no CI; tests are run locally, see docs/testing.md
	-pytest moved from the runtime dependencies to a "test" extra (with hypothesis and pytest-cov); install with pip install -e ".[test]"
	-enable_bokeh = False now works at every plot_level (previously plotting primitives failed with AttributeError, and SubtractOverscan failed at plot_level 3 when no Bokeh session was available)
	-Removed a duplicate alert_rti event definition from the RTI pipeline (no behaviour change)
	-Bokeh is replaced by Matplotlib for all plots. Saved PNG files keep their names and sizes; their appearance has changed
	-Live plot viewer: each pipeline process serves its plots at a URL on 127.0.0.1 (default port 5006; if taken, the next 9 ports are tried), printed at start-up. There is one viewer, and one browser tab, per process. The tab no longer opens by itself; open the printed URL, or set plot_viewer_open_browser = True
	-No bokeh server, Firefox, geckodriver, selenium or phantomjs are needed any more; the bokeh server launch and its 5 second start-up wait are gone from reduce_kcwi, start_kcwi_rti and smart_reduce_kcwi
	-New config keys (kcwi.cfg and kcwi_koarti.cfg): enable_plot_viewer, plot_viewer_port (default 5006) and plot_viewer_open_browser (default False). enable_plot_viewer controls the live viewer only; saved PNGs follow plot_level
	-enable_bokeh is deprecated: it is still honoured when enable_plot_viewer is absent, and a deprecation warning is logged once per process
	-Removed config keys plot_firefox_compat, plot_prewarm_firefox and terminate_on_failed_bokeh_start (old config files that still contain them load without error). A failed viewer start now always logs a warning and the reduction continues
	-Dropped the preference for non-snap Firefox/geckodriver added in PR #218 (v1.3.2): Firefox is no longer used
	-Dependencies: removed bokeh, selenium, phantomjs and the jinja2 < 3.1 pin; added tornado; replaced pyregion with regions. This fixes kcwi_masksky_ds9, which already imported regions and failed with ModuleNotFoundError in a clean install
	-smart_reduce_kcwi imports again (it imported check_bokeh_server, which no longer existed)
	-Removed requirements.txt and environment.yml: pyproject.toml is the only dependency list (install with pip install . or pip install -e ".[test]")
